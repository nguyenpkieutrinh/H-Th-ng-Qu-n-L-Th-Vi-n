1. Mở thư mục `src/`.
2. Nhấp đúp vào file `index.html` để mở trực tiếp trên trình duyệt web (Chrome, Edge,...).
*(Nếu dùng React/Vite: Mở Terminal tại thư mục `src/`, chạy `npm install` và `npm run dev`).*
